# HackHaven

Our Hack Club Haven game jam entry: a 3D browser game built with three.js.

## Folders
- `game/`: the real game. Only working, tested code goes here.
- `atharv/`: Atharv's workspace for prototypes and experiments.
- `shreyansh/`: Shreyansh's workspace for prototypes and experiments.
- `docs/`: submission checklist and pitch notes.

## Get started
```bash
git clone https://github.com/BurTheBear/HackHaven.git
cd HackHaven/game
bash setup.sh   # first time only
npm run dev
```

## Team rules
- `git pull` before you start, commit small, push often.
- Run `npm run build` in `game/` before pushing to main. Never push a broken build.
- Prototype in your own folder, then move working code into `game/src/game/` and tell the team.
- Don't edit someone else's folder, or a file someone else is working on, without asking.
- Art and sound: CC0 asset packs only (Kenney, Quaternius, KayKit, Poly Pizza, Poly Haven). Put them in `game/public/assets/` and list them in `game/CREDITS.md`. No AI-generated art or audio (Haven rule).
