# HackHaven

Our Hack Club Haven game jam entry: a 3D browser game built with three.js.

## Folders
- `game/`: the real game. Only working, tested code goes here.
- `atharv/`: Atharv's workspace for prototypes and experiments.
- `shreyansh/`: Shreyansh's workspace for prototypes and experiments.
- `docs/`: submission checklist and pitch notes.

## Get started
```bash
git clone https://github.com/BurTheBear/HackHaven.git
cd HackHaven/game
bash setup.sh   # first time only
npm run dev
```
